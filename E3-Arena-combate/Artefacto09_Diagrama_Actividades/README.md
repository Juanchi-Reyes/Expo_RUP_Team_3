Descripción
Este artefacto representa el flujo de funcionamiento del combate por turnos del módulo Arena de combate de RPG Manager. Permite visualizar las actividades que realizan el jugador y el sistema durante el desarrollo de una batalla.
Objetivo
Describir gráficamente la secuencia de actividades, decisiones y condiciones que controlan el desarrollo de un combate hasta determinar su finalización.
Flujo del proceso
El combate inicia con la selección de los participantes. Posteriormente, se ejecutan las acciones correspondientes a cada turno, el sistema procesa los resultados y actualiza el estado de los personajes. Este proceso se repite mientras el combate continúe.
Herramienta utilizada
PlantUML, utilizado para construir y generar el diagrama de actividades.
